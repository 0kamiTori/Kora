# Köra
Sistema académico de movilidad segura para mujeres: aplicación Android con perfiles de pasajera y conductora, web administrativa y backend compartido. Repositorio [0kamiTori/Kora](https://github.com/0kamiTori/Kora).

**Estado al 24/11/2026:** planificación y visión; todavía no hay aplicaciones ejecutables, APK ni despliegue. **Entrega tentativa del sistema completo: 14/01/2027.** Julian desarrolla móvil, John Ortiz web y ambos backend; unas 30 h semanales por persona. No se presenta como fecha institucional certificada ni como factibilidad comprobada.
