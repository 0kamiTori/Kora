# API

Base FastAPI API01 inicializada. Salud, preparación con PostgreSQL/PostGIS y política de registro cerrada; seis tablas y migración Alembic. No implementa registro, acceso o revisión administrativa funcionales.

Instalación, comandos, entorno y límites en [Documentación/BASE_API.md](../../Documentación/BASE_API.md). Conservar pyproject.toml, uv.lock y .python-version. Ninguna credencial de PostgreSQL debe llegar a móvil, web o Git.
