# Aplicación Android

Pendiente de inicializar con Flutter. Una aplicación con perfiles de pasajera y conductora. Arquitectura prevista: lib/core, lib/features/<funcion>/data y lib/features/<funcion>/presentation; añadir dominio solo cuando sea necesario.

Seguir docs/GUIA_CODEX.md y docs/SINCRONIZACION.md. Crear pubspec.yaml y pubspec.lock reales al inicializar. Seleccionar y fijar identificador Android de desarrollo antes de crear el proyecto; no usar el nombre provisional del repositorio como compromiso de identificador de tienda.

No hay código móvil, APK ni pruebas de dispositivo en esta etapa.
